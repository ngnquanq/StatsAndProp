# Paper Summary: BehavioCog: An Observation Resistant Authentication Scheme

**Citation:** Jagmohan Chauhan, Benjamin Zi Hao Zhao, Hassan Jameel Asghar, Jonathan Chan, and Mohamed Ali Kaafar, 2017, Financial Cryptography and Data Security (FC 2017).  
**Source:** `/home/nhatquang/Desktop/HCMUS Course/PhD_Applications/Macquarie_Kaafar/kaafar-papers/pdfs/1610.09044-behaviocog-authentication.pdf`  
**One-line takeaway:** BehavioCog combines cognitive challenge-response authentication with touch-based behavioral biometrics so that an observer must both infer the cognitive secret and mimic the user's gesture style.

## 1. What Problem Is This Paper Solving?

The paper targets authentication under observation: a user authenticates while someone can watch the screen and response entry, possibly through a video recording with replay control. Ordinary PINs, passwords, and graphical patterns fail under this model because one observation can reveal the secret. Cognitive authentication schemes are designed for this setting, but they are typically slow because humans must mentally compute many challenge-response rounds. Behavioral biometrics, such as touch gestures, can be faster but are vulnerable to mimicry and oracle-style adaptation if an attacker can repeatedly try to imitate the user.

BehavioCog's core idea is that these weaknesses are complementary. A cognitive scheme hides the real response under changing challenges, while a behavioral biometric makes each response harder to submit unless the attacker can imitate the target's writing dynamics. The resulting scheme aims to reduce the number of cognitive rounds while retaining empirical resistance to observation.

## 2. Main Contributions

- A hybrid authentication architecture in which each cognitive response is mapped to a touch-rendered symbol, and the verifier checks both the cognitive correctness and the behavioral biometric match.
- A new cognitive scheme inspired by HB and Foxtail-style protocols, using weighted subsets of pass-objects and modulo arithmetic, with analysis of random guessing, brute force, meet-in-the-middle, frequency analysis, Coskun-Herley-style attacks, and linearization.
- A gesture-based behavioral biometric based on writing selected symbols, especially "complex words" built from letters expected to produce more handwriting variation and harder mimicry.
- An Android implementation and a 41-participant user study covering symbol-set selection, full hybrid authentication, random attacks, video-based observation attacks, usability, and extended cognitive training.

## 3. Method Explained

**Intuition:** The user has a secret set of pass-emojis. In each round, the phone shows a challenge: a subset of emojis with numerical weights. The user mentally sums the weights of their pass-emojis modulo 5. Instead of typing the number, the user writes the word mapped to that result, such as `xman`, `bmwz`, `quak`, `hurt`, or `fogy`. The system accepts only if the written word is the right cognitive answer and if the writing pattern matches the enrolled user's behavioral template.

**Technical core:**

- The cognitive secret is a `k`-element subset from a global pool of `n` objects. In the Android study, the authors use `n = 180`, `k = 14`, challenge length `l = 30`, response modulus `d = 5`, and complex words as the symbol set.
- A challenge is `(a, w)`, where `a` is an `l`-object sequence and `w` contains weights in `Z_d`. If pass-objects appear in the challenge, the response is the sum of their weights modulo `d`; if no pass-object appears, the user outputs a random response in `Z_d`. This random empty-case behavior is intended to block response-dependent frequency attacks.
- The biometric classifier uses dynamic time warping (DTW). It builds templates from touch, stylometric, and device-interaction features such as coordinates, pressure, size, velocity, height, area, slope/path angles, curvature, accelerometer, gyroscope, and rotation features.
- Feature selection uses a wrapper-style sequential forward approach, optimizing for true positive rate near 1.0 while minimizing false positive rate.
- The adversary is passive but powerful in observation: they can watch or record authentication sessions and later attempt impersonation. The paper assumes the user's device is secure, which is narrower than the original insecure-channel model from Matsumoto and Imai.

## 4. Experiments And Results

- **Data:** The study used an Android Nexus 5x and 41 total participants across three phases. Phase 1 collected biometric samples from 22 actual participants, yielding 40 logical users across four symbol sets. Phase 2 tested the full scheme with 30 participants. Phase 3 revisited cognitive training with Group 3 participants.
- **Baselines / comparisons:** The paper compares symbol categories rather than running external authentication systems head-to-head: easy words, complex words, easy figures, and complex figures. It also situates authentication time against prior cognitive schemes such as CAS, HB, and Foxtail.
- **Metrics:** False positive rate (FPR), true positive rate (TPR), authentication time, registration time, success rate, cognitive errors, biometric errors, and attack success rates under random and video-based observation attacks.
- **Key findings:** Complex words performed best against observation. In the worst-case setting, average FPR was 0.05 for complex words versus 0.24 for easy words, 0.38 for easy figures, and 0.39 for complex figures, with TPR reported as 1.0 in the relevant feature-selection results. Against random attacks, symbol categories had almost 0% FPR.
- **Full scheme usability:** With the strongest training group in Phase 2 Session 1, average per-round time was 18.7 seconds: 12.2 seconds cognitive time, 5.6 seconds biometric time, and 0.8 seconds processing time. That group reached 85% success, with 15% cognitive errors and 0% biometric errors. After one week, success dropped to 50%, largely from cognitive errors.
- **Attack results:** The study reports 90 random and 90 video-based observation attacks. Each had 3.33% successful single attempts, none consecutive, and the authors state this was not statistically significant. Successful cases involved targets writing in block letters rather than cursive.
- **Training effect:** Phase 3's improved cognitive training raised Group 3 success to 94% in Session 1 and 86% after one week, suggesting that pass-emoji confusion, not modular arithmetic alone, caused many cognitive errors.
- **Security target:** The authors estimate that with complex-word FPR around 0.05 and cognitive random-guess probability around 0.256, two rounds give security around `1.5 x 10^-4`, close to a 4-digit PIN, while remaining observation-resistant in the studied setting.

## 5. Limitations And Risks

- The observation resistance of the biometric component is empirical, not a formal guarantee. The authors explicitly note that mimicry difficulty for complex cursive words needs further study.
- The threat model assumes a secure device and does not fully handle malware, compromised sensors, or server-side compromise.
- Usability is fragile: 14 pass-emojis were difficult for many users, and long-term recognition required stronger training.
- The system may leak timing information because response time varies with the number of pass-emojis in the challenge.
- Theme-based emoji selection creates guessability risk; some attackers guessed several target pass-emojis, including one case with 11 correct guesses.
- The user study is modest in scale and controlled; deployment in real mobile settings may introduce drift, distraction, posture changes, and sensor variation.

## 6. Why This Matters For Nguyen Nhat Quang's IAM/security-ML PhD Direction

For an IAM/security-ML PhD direction, this paper is useful because it sits at the intersection of authentication protocol design, behavioral biometrics, adversarial evaluation, and usable security. It shows how identity assurance can be treated as a layered decision process: not just "what the user knows" or "how the user behaves," but a combined protocol in which each factor changes the attacker's uncertainty.

The paper is also a good example of security-ML evaluation discipline. The classifier is not presented as a generic biometric model; it is evaluated under a concrete impersonation threat, including video replay access. For future IAM work, this supports a research angle around adaptive risk scoring, behavioral authentication under observation, detector thresholding, and the limits of empirical biometric security.

At the same time, it is a cautionary paper: the ML component does not solve authentication by itself, and security claims depend on protocol context, user training, and attacker capability. This is directly relevant when positioning IAM systems that combine behavioral signals with cryptographic or policy-level controls.

## 7. How To Use This Paper

- **Cite it for:** observation-resistant authentication, hybrid cognitive-plus-behavioral authentication, touch-gesture biometrics under mimicry attacks, and usable-security tradeoffs in smartphone IAM.
- **Do not cite it for:** a complete formal solution to observation-resistant authentication, proof of biometric unforgeability, or evidence that 14-object graphical secrets are broadly usable without training.
- **Use in a PhD proposal:** position it as a bridge between classical cognitive authentication and modern behavioral IAM, then argue for stronger adversarial ML evaluation, longitudinal studies, privacy-preserving template protection, or adaptive multi-factor authentication.
- **Follow-up reading:** Matsumoto and Imai on human identification over insecure channels; Hopper-Blum and Foxtail-style cognitive protocols; work on targeted mimicry attacks against touch biometrics; and papers on privacy-preserving biometric template protection such as fuzzy vaults or functional encryption.
