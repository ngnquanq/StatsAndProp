# Stanford CS229 — Machine Learning
**Instructor:** Andrew Ng (original) / Percy Liang, Tengyu Ma (recent)
**Course page:** https://cs229.stanford.edu/
**YouTube (2018):** https://www.youtube.com/playlist?list=PLoROMvodv4rMiGQp3WXShtMGgzqpfVfbU

The canonical graduate ML theory course. Where NTU's Hsuan-Tien Lin course covers the *why* of learning (VC theory), CS229 covers the *math* of algorithms (derivations, proofs, probability). Use this to fill gaps in the NTU ML course.

## CS229 lecture notes contents (cs229_lecture_notes.pdf)

| Section | Topics |
|---|---|
| Part I | Supervised learning: linear/logistic regression, GLMs |
| Part II | Generative models: GDA, Naive Bayes |
| Part III | SVMs: functional/geometric margins, dual, kernels |
| Part IV | Learning theory: bias-variance, VC dimension, regularization |
| Part V | Deep learning: backprop, CNNs, RNNs |
| Part VI | Reinforcement learning basics |
| Part VII | Unsupervised: k-means, EM, PCA, ICA |
